# PAGINAS.md — mapa das landing pages VermeFree

> Atualizar esta tabela toda vez que uma LP for criada, alterada de status ou publicada. Ver fluxo completo em `vermefree-lp-kit/COMO-USAR.md`.

## Convenção de link

Toda LP publicada segue o padrão:

```
https://raw.githack.com/operacionalvermfree/copyvermfree/lp/landing-<slug>/index.html
```

Branch de publicação: `lp`. Pasta: `landing-<slug>/index.html` (HTML autocontido).
