# zips/

Zips **pequenos e essenciais** (< 25MB) podem subir direto aqui, no repositório GitHub — sem passar pelo Drive.

Exemplos do que cabe aqui: um pacote de ícones otimizados, um export leve de assets já cortados/comprimidos pra uma LP específica, um zip de referência técnica curto que vale versionar junto com o código.

## O que NÃO vai aqui

Qualquer coisa pesada (fotos em alta, vídeo, PSD, zip de referência grande) vai para o Google Drive, em `VermeFree/LP-KIT/01_referencias-zips/` (matéria-prima bruta) — ver `FONTES.md` na raiz do kit para o ID/link da pasta. Se o arquivo sozinho já beira ou passa de 25MB, não é pra vir pra cá.

Nenhum zip foi commitado ainda — pasta criada como parte da fundação do LP-KIT.
